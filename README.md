# DeFi Yield Aggregator

Multi-chain yield optimizer that automatically finds and compounds the best APY.

## Features
- Multi-chain support (Ethereum, BSC, Polygon, Arbitrum)
- Auto-compounding
- Gas optimization
- Risk scoring

## Tech Stack
- Python 3.11+
- Web3.py
- DeFi protocols integration

## Status
🚧 Active development - Protocol integration phase


## Usage

```bash
# Run the script
python main.py

# With custom parameter (if supported)
python main.py <parameter>
```
